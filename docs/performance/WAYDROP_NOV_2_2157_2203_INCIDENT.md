```sql
  (name,bucket_id,owner,owner_id,metadata,version,is_delete_marker,is_versioned)
VALUES ($1,$2,$3,$4,$5,$6,$7,$8)
ON CONFLICT (bucket_id,name COLLATE "C") WHERE archived_at IS NULL
DO UPDATE SET owner=EXCLUDED.owner, owner_id=EXCLUDED.owner_id,
              metadata=EXCLUDED.metadata, version=EXCLUDED.version
RETURNING *, /* replaced object/version/marker lookups */ ...;
```

There are eight indexes, including the exact partial unique current-version conflict arbiter, version/nonversioned unique indexes and prefix/name indexes. Constraints are the primary key and bucket foreign key. Two noninternal triggers exist: a DELETE protection trigger and a trivial BEFORE UPDATE `updated_at=now()` trigger. **No custom INSERT notification/dispatch trigger was found on this table.** A conflicting unique insertion, bucket FK lock, internal Storage locking, index/WAL/I/O stall or wider database stall can delay a metadata write; none is identified by the retained57014 record alone. No missing conflict index or expensive application INSERT trigger is demonstrated. Versioning indexes are not removed.

Parcel INSERT policy is authenticated bucket equality; public parcel SELECT is bucket equality; parcel UPDATE checks owner.
